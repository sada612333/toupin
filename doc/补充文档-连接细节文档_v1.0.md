## 连接细节文档

### 一、现有连接基础
- 基于 WebRTC 实现局域网连接
- 当前仅支持发送端主动搜索接收端、手动输入 IP 连接
- 核心依赖：WebRTC 核心 SDK、安卓网络 API

### 二、共性优化需求（适配双模块）

#### 1. 扩展连接方式
- **热点连接**：发送端开启热点，接收端连接热点实现投屏
- **二维码连接**：通过扫描二维码快速建立设备间连接
- 新增方式需与 WebRTC 局域网连接兼容，解决局域网不稳定问题

#### 2. 提升连接体验
- 优化 WebRTC 配置参数，缩短连接耗时
- 优化设备搜索算法
- 增加连接失败重试机制
- 实时显示连接进度
- 提供统一的连接异常提示

#### 3. 适配要求
- 兼容不同安卓版本的网络 API 及 WebRTC 版本
- 支持多设备同时搜索
- 解决部分设备无法搜索到接收端的问题
- 确保双模块连接状态同步
- 与 Jetpack Compose 界面状态联动

### 三、模块专属连接逻辑

#### 发送端
- 连接触发逻辑
- 连接参数配置
- 多连接方式切换逻辑
- 连接状态上报逻辑

#### 接收端
- 连接监听逻辑
- 连接响应逻辑
- 多连接方式适配逻辑
- 连接保活与异常处理逻辑

### 四、编码要求
- 连接相关功能按单一功能点拆分（如 WebRTC 连接建立、热点连接开启、二维码生成与识别）
- 每个功能点可独立验证、可测试，设计专属测试用例
- 日志输出遵循统一规范：
  - 重点标注连接模块、功能点、连接状态及异常信息
  - 便于定位连接相关问题

### 五、依赖适配
- 连接相关依赖组件（WebRTC SDK、热点/二维码相关 API）需与 kitlon、gradle、安卓 gradle 插件适配
- 重构时若升级依赖，需提前排查版本冲突
