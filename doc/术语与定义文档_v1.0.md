## 术语与定义文档

### 一、专业术语

#### 发送端（Sender）
基于 Jetpack Compose 开发，负责采集、编码、通过 WebRTC 传输投屏内容，集成连接、性能监控逻辑的安卓设备（手机/平板）。

#### 接收端（Receiver）
基于 Jetpack Compose 开发，负责通过 WebRTC 接收、解码、显示投屏内容，集成连接响应、性能监控逻辑的安卓设备（电视/盒子）。

#### Jetpack Compose
谷歌推出的安卓 UI 开发框架，用于搭建项目发送端、接收端的用户界面，具有组件化、自适应等特性。

#### WebRTC
实时通信技术，项目中用于实现局域网内投屏数据（音视频）的实时传输。

#### 音视频编码（Encoding）
将发送端采集的音视频数据压缩处理，便于 WebRTC 传输的过程。

#### 音视频解码（Decoding）
将接收端通过 WebRTC 获取的压缩数据还原，便于显示的过程。

### 二、自定义术语

#### 局域网连接（LAN Connection）
项目当前基础连接方式，通过 WebRTC 技术实现设备间数据传输。

#### 热点连接（Hotspot Connection）
新增备用连接方式，通过发送端开启热点，接收端连接热点实现投屏，可与 WebRTC 传输兼容。

#### 二维码连接（QR Code Connection）
新增备用连接方式，通过扫描二维码快速建立设备间连接，可与 WebRTC 传输兼容。

#### 重构（Refactoring）
在不改变现有功能（含 Jetpack Compose UI、WebRTC 传输）的前提下，优化代码结构、模块划分，降低耦合度。

### 三、缩写说明
- **API**：应用程序接口（Application Programming Interface）
- **SDK**：软件开发工具包（Software Development Kit）
- **UI**：用户界面（User Interface）
- **LAN**：局域网（Local Area Network）
- **fps**：帧率（Frames Per Second）
- **ms**：毫秒（Millisecond）
