## 项目核心概述

### 一、项目核心定位
安卓平台投屏工具，基于 Jetpack Compose 开发，分为发送端与接收端两个核心模块：
- **发送端**：运行于手机/安卓设备，负责采集、编码并输出投屏内容
- **接收端**：运行于安卓电视/盒子等大屏设备，负责接收并显示投屏内容

当前已通过 WebRTC 实现局域网内音视频数据传输功能。

### 二、核心目标
完善基础投屏功能，完成界面、连接、性能、架构等多维度优化，提升投屏稳定性、流畅度及用户体验，基于现有 Jetpack Compose 框架和 WebRTC 传输能力迭代升级。

### 三、核心价值
解决安卓设备间投屏操作繁琐、连接不稳定、界面不美观等痛点，依托 Jetpack Compose 的 UI 优势和 WebRTC 的高效传输能力，提供便捷、高效的跨设备投屏解决方案。

### 四、技术栈
- **UI 框架**：Jetpack Compose
- **传输技术**：WebRTC
- **平台**：Android 8.0+
