# 物理安卓机 → AVD 模拟器端口转发教程（Manjaro Linux）
专为**局域网物理手机访问安卓模拟器(AVD)** 设计，解决 Linux 下 ADB 仅监听本地、无法外网访问的问题。

---

## 一、核心说明
1. **ADB 默认仅监听 127.0.0.1** → 物理手机无法直接连接
2. **方案**：ADB 转发模拟器端口 + `socat` 暴露局域网访问
3. **端口规划**
    - 模拟器端口：`8080`
    - ADB 本地转发端口：`8081`（避免冲突）
    - 物理手机访问端口：`8080`

---

## 二、一键可执行命令（带注释，点击复制单独执行）
### 1. 清空所有旧的端口转发（必执行）
```bash
# 作用：删除系统中所有adb端口转发规则，防止端口冲突
adb -s emulator-5554 forward --remove-all
```

### 2. ADB 转发：电脑 8081 → 模拟器 8080
```bash
# 作用：将本地(电脑)8081端口流量，转发到AVD模拟器的8080端口
# 格式：adb -s 设备名 forward 本地端口 模拟器端口
adb -s emulator-5554 forward tcp:8081 tcp:8080 
```

### 3. socat 暴露端口：允许局域网访问 8080
```bash
# 作用：将本机8080端口绑定0.0.0.0（所有网卡），转发到本地8081端口（对接adb）
# TCP-LISTEN:8080 → 监听8080端口
# bind=0.0.0.0 → 允许所有局域网设备访问
# TCP:127.0.0.1:8081 → 转发到本地8081端口
socat TCP-LISTEN:8080,fork,bind=0.0.0.0 TCP:127.0.0.1:8081
```

---

## 三、物理手机连接方式
1. **查看电脑局域网IP**
```bash
ip a
```
找到 `192.168.x.x` 格式的IP（如 `192.168.1.105`）

2. **手机访问地址**（手机与电脑连**同一WiFi**）
```
http://你的电脑局域网IP:8080
```
示例：`http://192.168.1.105:8080`

---

## 四、使用说明（文档便捷操作技巧）
### 1. 单独执行命令方法
- 在 VS Code / Typora /  Obsidian 等 Markdown 编辑器中
- **鼠标悬停代码块** → 点击**复制按钮** → 粘贴到终端直接运行
- 三条命令**按顺序执行**

### 2. 关闭转发
- 终止 `socat`：终端按 `Ctrl + C`
- 清空转发：执行第一条命令即可

### 3. 常见问题
- 端口占用：换 `8082/8083` 等端口即可
- 无法访问：确保手机和电脑在**同一局域网**
